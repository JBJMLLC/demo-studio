# Security policy

Please do not report a vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository (Security → Advisories → Report a vulnerability). Include the affected version, a concise impact description, and safe reproduction steps. Do not attach real credentials, customer data, or unredacted browser recordings.

The default workflow is local, but captured browser content and generated media can still contain sensitive information. Review the declared target, workspace, frames, captions, logs, and output before sharing them. Never place secrets in a plan or source file.
