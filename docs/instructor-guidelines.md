# Instructor guidelines behind the skills

The teaching and delivery guidance in the skills follows public guidance from course platforms, accessibility standards, and video-learning research. This page lists the sources so the numbers can be rechecked when platforms change them. Platform requirements change; check the destination's current specification before you rely on a value here.

## Not adopted as rules

- Lecture lengths of 2–6 minutes for Udemy, about 5 minutes for Pluralsight clips, and course-length rules for Skillshare and Coursera appear only in secondary sources. The skills use the research-backed 6-minute guide instead.
- No major platform publishes a loudness target for uploads; a commonly cited −14 LUFS for YouTube is not an official specification.
- Sources disagree about pointing. egghead uses the cursor to direct attention, while Pluralsight forbids circling and zoom. The skills ask for one consistent, recorded choice per series.
