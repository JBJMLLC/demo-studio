# Demo Studio documentation

Demo Studio helps you plan a product walkthrough around the viewer's goal and the proof the product can show. Its local tools capture a reviewed plan in a real browser and check the resulting screen and speech.

Start with the [quickstart](quickstart.md), then use the [plan format](plan-format.md) as a reference.

## Defaults

The included example uses synthetic data and a loopback-only local web server. Captioned output is the default; paid provider credentials are optional. Independent semantic review is required before publication. A human can run the workflow sequentially; parallel or paid multi-agent services are not required.
